# Project Roadmap: Integration to Deployment

안드로이드 앱 통합부터 AWS 서버 배포까지의 전체 진행 순서입니다.
모든 과정이 처음이라면 이 순서대로 하나씩 진행하는 것을 권장합니다.

---

## Phase 1: 로컬 통합 테스트 (Local Integration)
**목표:** 서버를 AWS에 올리기 전에, 내 컴퓨터(로컬)에서 안드로이드 앱과 통신이 잘 되는지 확인합니다.

1.  **네트워크 환경 맞추기**
    *   백엔드 개발자(나)와 안드로이드 개발자(파트너)가 **같은 와이파이**에 접속합니다.
    *   (또는 핫스팟을 켜서 같이 접속합니다.)

2.  **내 컴퓨터 IP 확인**
    *   CMD(명령 프롬프트)를 열고 `ipconfig` 입력.
    *   `IPv4 주소` 확인 (예: `192.168.0.15`)

3.  **Django 설정 변경 (`settings.py`)**
    *   안드로이드 폰이 내 컴퓨터에 접속할 수 있도록 허용합니다.
    ```python
    ALLOWED_HOSTS = ['192.168.0.15', 'localhost', '127.0.0.1']
    ```

4.  **서버 실행**
    ```bash
    python manage.py runserver 0.0.0.0:8000
    ```
    *   `0.0.0.0`은 "외부 접속을 허용하겠다"는 뜻입니다.

5.  **안드로이드 코드 수정 (파트너)**
    *   Retrofit의 `BASE_URL`을 내 IP로 변경해달라고 요청합니다.
    *   예: `http://192.168.0.15:8000/api/places/`
    *   **테스트:** 앱에서 버튼을 눌렀을 때 내 서버 로그에 반응이 오는지 확인합니다.

## Phase 2: 서버 포장하기 (Dockerization)
**목표:** 내 컴퓨터에서 잘 돌아가는 서버를, AWS에서도 똑같이 돌아가게 만들기 위해 '컨테이너'로 포장합니다.

1.  **필수 파일 생성** (`DEPLOY_GUIDE.md` 참고)
    *   `Dockerfile`: 서버 설치 설명서
    *   `docker-compose.yml`: 서버 실행 설명서
    *   `requirements.txt`: 필요한 라이브러리 목록 (`pip freeze > requirements.txt`)

2.  **로컬에서 Docker 테스트**
    *   Docker Desktop을 설치하고 실행합니다.
    *   프로젝트 폴더에서 다음 명령어 실행:
    ```bash
    docker-compose up --build
    ```
    *   오류 없이 실행되는지 확인합니다. (DB 연결 오류 등이 없는지 체크)

## Phase 3: 클라우드 서버 준비 (AWS EC2)
**목표:** 24시간 켜져 있는 가상의 컴퓨터(EC2)를 빌립니다.

1.  **AWS 회원가입 및 로그인**
2.  **EC2 인스턴스 생성 (서버 빌리기)**
    *   **OS:** Ubuntu 22.04 LTS (가장 무난함)
    *   **인스턴스 유형:** t2.micro (프리티어 무료)
    *   **키 페어:** `.pem` 파일을 다운로드받아 잘 보관합니다. (잃어버리면 서버 접속 불가)

3.  **보안 그룹 설정 (방화벽)**
    *   인바운드 규칙 편집:
        *   `SSH (22)`: 내 IP
        *   `HTTP (80)`: 위치 무관 (0.0.0.0/0)
        *   `사용자 지정 TCP (8000)`: 위치 무관 (0.0.0.0/0) - *테스트용*

4.  **탄력적 IP (Elastic IP) 할당**
    *   서버를 껐다 켜도 IP가 바뀌지 않도록 고정 IP를 할당받아 EC2에 연결합니다.

---

## Phase 4: 배포 및 실행 (Deployment)
**목표:** 내 코드를 AWS 컴퓨터로 옮겨서 실행합니다.

1.  **코드 업로드 (Github 이용 추천)**
    *   내 코드를 Github 레포지토리에 `push` 합니다.
    *   `.env` 파일이나 `db.sqlite3` 같은 중요/데이터 파일은 올리지 않도록 주의합니다 (`.gitignore`).

2.  **AWS 서버 접속**
    *   CMD 또는 터미널에서 SSH 접속:
    ```bash
    ssh -i "내키파일.pem" ubuntu@내-AWS-IP주소
    ```

3.  **서버 세팅**
    *   `DEPLOY_GUIDE.md`의 **3. AWS EC2 배포 절차**를 따라 Docker를 설치합니다.
    *   Github에서 코드를 `git clone` 받습니다.
    *   `.env` 파일을 서버에서 직접 생성합니다 (`nano .env`).

4.  **서버 실행**
    ```bash
    sudo docker-compose up -d --build
    ```

---

## Phase 5: 최종 연결 (Release)
**목표:** 안드로이드 앱이 AWS 서버를 바라보게 합니다.

1.  **안드로이드 코드 수정**
    *   `BASE_URL`을 AWS의 탄력적 IP(고정 IP)로 변경합니다.
    *   예: `http://3.12.34.56:8000/api/places/`

2.  **최종 테스트**
    *   앱이 정상적으로 데이터를 받아오는지 확인합니다.
    *   이제 내 컴퓨터를 꺼도 앱이 작동합니다!
